Aunque los **SVMs** son más conocidos por su aplicación en problemas de clasificación, también pueden ser utilizados para **regresión**. En este caso, en lugar de tratar de encontrar un hiperplano que separe las clases, el objetivo es encontrar un **hiperplano de regresión** que prediga un valor continuo.

### ¿Qué es la regresión en SVM?

La **regresión en SVM**, conocida como **Support Vector Regression (SVR)**, intenta encontrar un hiperplano que no solo ajuste los datos de entrenamiento, sino que también minimice la cantidad de errores de predicción dentro de un margen especificado. En lugar de tratar de clasificar los datos, el objetivo de SVR es predecir valores continuos (por ejemplo, predecir el precio de una casa basado en ciertas características).

La principal diferencia entre la clasificación y la regresión es que, en la regresión, no estamos buscando clases disjuntas, sino un **valor numérico continuo**. Sin embargo, la idea subyacente de maximizar el margen y permitir algunos errores sigue siendo la misma.

### El Margen en la Regresión

En la regresión, el concepto de margen se adapta para permitir que los puntos de datos caigan dentro de un "margen de tolerancia" alrededor del hiperplano de regresión. Este margen se define por un parámetro \( \epsilon \), que es el margen dentro del cual no se aplican penalizaciones por los errores.

- Si un punto de datos está dentro de este margen, no se le penaliza.
- Si el punto de datos se encuentra fuera de este margen, se le aplica una penalización, y se calcula el error.

### Fórmula del Problema de Optimización en SVR

El objetivo de la regresión con SVM es encontrar una función \( f(x) = w \cdot x + b \) que minimice el siguiente costo:

$$
\text{minimizar } \frac{1}{2} \|w\|^2 + C \sum_{i=1}^{N} (\xi_i + \xi_i^*)
$$

Donde:
- \( \xi_i \) y \( \xi_i^* \) son las variables de error para cada punto de datos.
- \( C \) es el parámetro de regularización que penaliza los errores grandes.
- El parámetro \( \epsilon \) determina el margen de tolerancia alrededor del hiperplano.

La restricción es que los errores de predicción deben caer dentro del margen de tolerancia, es decir:

$$
|y_i - (w \cdot x_i + b)| \leq \epsilon + \xi_i
$$

### Ejemplo de Implementación de SVR

A continuación, implementamos un modelo de **Support Vector Regression (SVR)** en Python utilizando Scikit-learn.

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.svm import SVR

# Generar datos de ejemplo para regresión
X = np.reshape(np.linspace(0, 10, 100), (-1, 1))
y = np.sin(X).ravel()  # Generamos valores de y como la función seno

# Crear el modelo SVR con un kernel RBF
svr = SVR(kernel='rbf', C=100, epsilon=0.1)

# Ajustar el modelo
svr.fit(X, y)

# Predecir valores con el modelo
y_pred = svr.predict(X)

# Visualizar los resultados
plt.scatter(X, y, color='blue', label='Datos reales')
plt.plot(X, y_pred, color='red', label='Modelo SVR')
plt.title('Regresión con SVM (SVR)')
plt.xlabel('X')
plt.ylabel('y')
plt.legend()
plt.show()
\```

En este código:
1. Generamos un conjunto de datos basado en la función seno, que es un problema típico de regresión.
2. Creamos un modelo **SVR** con un **kernel RBF**.
3. Entrenamos el modelo y visualizamos los resultados, comparando las predicciones con los datos reales.
