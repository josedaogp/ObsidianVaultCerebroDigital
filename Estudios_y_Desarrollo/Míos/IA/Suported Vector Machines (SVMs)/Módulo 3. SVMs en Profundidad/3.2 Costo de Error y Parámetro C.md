Uno de los aspectos más importantes en el diseño de un **SVM** es el control del **costo de error**, que se gestiona mediante el parámetro **C**. Este parámetro juega un papel crucial en la regularización del modelo y en el equilibrio entre la complejidad del modelo y el margen de separación.

### ¿Qué es el parámetro C?

El parámetro **C** controla el **compromiso entre obtener un margen más amplio y minimizar el error de clasificación**. Es una forma de **regularización** en SVM. 

- Si el valor de **C** es **alto**, el SVM buscará un margen más estrecho, pero con menos errores de clasificación. Esto puede llevar a un modelo más complejo que podría **sobreajustarse** (overfitting) a los datos de entrenamiento.
- Si el valor de **C** es **bajo**, el SVM permitirá más errores de clasificación (es decir, más puntos caen dentro del margen o incluso al otro lado del margen) y tratará de encontrar un margen más amplio. Esto puede resultar en un **modelo más generalizado**, que podría ser menos sensible al ruido de los datos.

### Formulación Matemática

El parámetro **C** se introduce en la formulación de SVM en el objetivo de optimización de la siguiente manera:

$$
\text{minimizar } \frac{1}{2} \|w\|^2 + C \sum_{i=1}^{N} \xi_i
$$

Donde:
- \( \|w\|^2 \) es la norma del vector normal al hiperplano (que estamos minimizando para maximizar el margen).
- \( \xi_i \) son las variables de error que permiten que algunos puntos caigan en el otro lado del margen.
- **C** es el parámetro que controla el trade-off entre el margen máximo y la penalización por los errores de clasificación.

### ¿Cómo afecta C al modelo?

- **C alto**: Minimiza más los errores de clasificación, pero puede generar un margen pequeño.
- **C bajo**: Permite más errores, pero genera un margen más amplio.

### Visualización del Efecto de C

Veamos cómo cambia el modelo SVM con diferentes valores de **C**. A continuación, implementamos dos modelos, uno con un valor bajo de **C** y otro con un valor alto de **C**, y comparamos sus márgenes y clasificaciones.

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn import datasets
from sklearn.svm import SVC

# Crear un conjunto de datos de 2 características
X, y = datasets.make_classification(n_samples=100, n_features=2, n_classes=2)

# Modelo SVM con C bajo (C=0.1)
model_low_C = SVC(kernel='linear', C=0.1)
model_low_C.fit(X, y)

# Modelo SVM con C alto (C=100)
model_high_C = SVC(kernel='linear', C=100)
model_high_C.fit(X, y)

# Crear un rango de valores para los gráficos
xx = np.linspace(X[:, 0].min(), X[:, 0].max(), 30)
yy = np.linspace(X[:, 1].min(), X[:, 1].max(), 30)
xx, yy = np.meshgrid(xx, yy)

# Predecir la clase para los puntos de la malla
Z_low_C = model_low_C.predict(np.c_[xx.ravel(), yy.ravel()]).reshape(xx.shape)
Z_high_C = model_high_C.predict(np.c_[xx.ravel(), yy.ravel()]).reshape(xx.shape)

# Graficar los resultados

plt.figure(figsize=(14, 6))

# Subgráfico 1: SVM con C bajo
plt.subplot(1, 2, 1)
plt.contourf(xx, yy, Z_low_C, alpha=0.8, cmap='coolwarm')
plt.scatter(X[:, 0], X[:, 1], c=y, cmap='winter', edgecolors='k')
plt.title('SVM con C Bajo (C=0.1)')
plt.xlabel('Característica 1')
plt.ylabel('Característica 2')

# Subgráfico 2: SVM con C alto
plt.subplot(1, 2, 2)
plt.contourf(xx, yy, Z_high_C, alpha=0.8, cmap='coolwarm')
plt.scatter(X[:, 0], X[:, 1], c=y, cmap='winter', edgecolors='k')
plt.title('SVM con C Alto (C=100)')
plt.xlabel('Característica 1')
plt.ylabel('Característica 2')

plt.tight_layout()
plt.show()
\```

En este código:
- Se crean dos modelos SVM con diferentes valores de **C**.
- Luego, entrenamos ambos modelos con el mismo conjunto de datos.
- Visualizamos las fronteras de decisión para ambos modelos, lo que muestra cómo el valor de **C** afecta la forma del margen y la clasificación de los puntos.
