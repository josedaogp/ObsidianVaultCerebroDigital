Módulo 2: Conceptos Fundamentales

Los SVMs pueden utilizarse para **clasificación** y **regresión**:

- **Clasificación**: Determinar a qué clase pertenece una nueva instancia de datos (por ejemplo, si una imagen contiene un gato o un perro).
- **Regresión**: Predecir un valor continuo, como el precio de una casa en función de sus características (número de habitaciones, ubicación, etc.).

### Ejemplo:
Imagina un conjunto de datos de dos clases (perros y gatos) y quieres entrenar un modelo para clasificar nuevas imágenes. El SVM buscará un hiperplano que divida las imágenes de perros y gatos en su espacio de características.

---

## 2.2 Espacios de Características

El **espacio de características** es el espacio multidimensional en el que se encuentran las muestras de datos. Cada dimensión del espacio corresponde a una de las características de los datos. Por ejemplo, si estás clasificando frutas basadas en su peso y color, el espacio de características sería bidimensional, con una dimensión para el peso y otra para el color.

---

## 2.3 Hiperplanos y Márgenes

El **hiperplano** es la línea (en 2D), el plano (en 3D) o el hiperplano (en espacios de más de 3 dimensiones) que separa las clases de datos. El **margen** es la distancia entre el hiperplano y los puntos más cercanos de cada clase. Los SVMs intentan maximizar este margen, lo que mejora la generalización del modelo.

### Visualización:
Imagina que tienes puntos azules y rojos. El objetivo es encontrar una línea (en 2D) que los separe, y entre más lejos esté esta línea de los puntos más cercanos de cada clase, mejor.

---

## 2.4 El Modelo Lineal de SVM

En su forma más básica, el SVM intenta encontrar un hiperplano en un espacio lineal que divida las clases de manera óptima. Si los datos no se pueden separar linealmente (es decir, no existe un hiperplano que los divida sin error), entonces se pueden aplicar **kernels** para transformar los datos en un espacio de mayor dimensión donde sí puedan ser separados.

---

## 2.5 Funciones de Kernel

Un **kernel** es una función matemática que transforma los datos en un espacio de mayor dimensión donde un hiperplano lineal puede separar las clases. Los kernels más comunes son:
- **Kernel lineal**: No transforma los datos, los mantiene en su espacio original.
- **Kernel polinómico**: Transforma los datos de manera que pueden separarse con un hiperplano.
- **Kernel gaussiano (RBF)**: Utiliza una función de base radial para transformar los datos en un espacio de dimensiones muy altas.

## Ejercicio Práctico

Imagina que tienes un conjunto de datos con dos características (X1, X2) y etiquetas (0 o 1). Usa el siguiente código para entrenar un SVM con un kernel lineal:

```python
from sklearn import datasets
from sklearn.svm import SVC
import matplotlib.pyplot as plt

# Cargar datos de ejemplo
X, y = datasets.make_classification(n_samples=100, n_features=2, n_classes=2)

# Crear el modelo SVM
clf = SVC(kernel='linear')

# Entrenar el modelo
clf.fit(X, y)

# Visualización de los resultados
plt.scatter(X[:, 0], X[:, 1], c=y, cmap='winter')
plt.title('SVM con Kernel Lineal')
plt.show()
