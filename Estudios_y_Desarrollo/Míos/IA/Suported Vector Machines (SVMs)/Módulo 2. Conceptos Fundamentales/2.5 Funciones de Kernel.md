Los **kernels** son funciones matemáticas que permiten transformar datos no linealmente separables en un espacio de características de mayor dimensión, donde pueden separarse linealmente. Esta técnica es fundamental para los SVMs cuando los datos no son lineales, ya que permite que el SVM se convierta en una poderosa herramienta para resolver problemas no lineales.

### ¿Qué es un Kernel?

Un **kernel** es una función que calcula el producto interno entre dos vectores transformados en un espacio de características de mayor dimensión sin necesidad de realizar explícitamente la transformación. Gracias a los kernels, los SVMs pueden trabajar en espacios de características de dimensiones muy altas sin tener que lidiar directamente con la complejidad computacional de realizar la transformación.

El **truco del kernel** es que, al usar la propiedad del producto interno, podemos operar en un espacio de características elevado sin tener que calcular las coordenadas explícitas de las instancias en ese espacio. Esto permite que los SVMs se adapten a problemas no lineales sin tener que procesar directamente las características transformadas.

---

### Tipos de Kernels

Existen varios tipos de funciones de kernel, siendo los más comunes los siguientes:

1. **Kernel Lineal**:
   - Este kernel no transforma los datos, los mantiene en su espacio original.
   - Se usa cuando los datos ya son separables linealmente.

   $$ K(x, x') = x \cdot x' $$

2. **Kernel Polinómico**:
   - Este kernel mapea los datos a un espacio de mayor dimensión de manera polinómica.
   - La forma general del kernel polinómico es:

   $$ K(x, x') = (x \cdot x' + c)^d $$

   Donde \( c \) es una constante y \( d \) es el grado del polinomio.

3. **Kernel Gaussiano (RBF - Radial Basis Function)**:
   - Este es uno de los kernels más populares y poderosos, especialmente para datos no lineales.
   - La forma del kernel gaussiano es:

   $$ K(x, x') = \exp \left( -\frac{\|x - x'\|^2}{2\sigma^2} \right) $$

   Donde \( \sigma \) es un parámetro que controla la amplitud de la función de base radial.

4. **Kernel Sigmoide**:
   - Este kernel está basado en la función sigmoide utilizada en redes neuronales.
   - La forma del kernel sigmoide es:

   $$ K(x, x') = \tanh(\alpha x \cdot x' + c) $$

   Donde \( \alpha \) y \( c \) son parámetros ajustables.

---

### ¿Cómo Funcionan los Kernels?

Los kernels permiten que el SVM transforme el problema en un espacio de características de mayor dimensión sin necesidad de realizar explícitamente la transformación. Esto es crucial porque muchos problemas de clasificación y regresión que no pueden ser resueltos con un SVM lineal, pueden ser resueltos con un SVM utilizando un kernel adecuado.

### Ejemplo de Implementación con Kernels

A continuación, mostramos un ejemplo de cómo usar un kernel polinómico y un kernel RBF para clasificar un conjunto de datos no linealmente separable.

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn import datasets
from sklearn.svm import SVC

# Crear un conjunto de datos no lineales
X, y = datasets.make_circles(n_samples=100, factor=0.5, noise=0.1)

# Crear un modelo SVM con kernel RBF
model_rbf = SVC(kernel='rbf', gamma='scale')

# Entrenar el modelo
model_rbf.fit(X, y)

# Crear un gráfico de decisión para kernel RBF
xx, yy = np.meshgrid(np.linspace(X[:, 0].min(), X[:, 0].max(), 100),
                     np.linspace(X[:, 1].min(), X[:, 1].max(), 100))
Z = model_rbf.predict(np.c_[xx.ravel(), yy.ravel()])
Z = Z.reshape(xx.shape)

plt.contourf(xx, yy, Z, alpha=0.8)
plt.scatter(X[:, 0], X[:, 1], c=y, edgecolors='k', marker='o', cmap='winter')
plt.title('Clasificación con Kernel RBF')
plt.xlabel('Característica 1')
plt.ylabel('Característica 2')
plt.show()

# Crear un modelo SVM con kernel Polinómico
model_poly = SVC(kernel='poly', degree=3, coef0=1)

# Entrenar el modelo
model_poly.fit(X, y)

# Crear un gráfico de decisión para kernel Polinómico
Z_poly = model_poly.predict(np.c_[xx.ravel(), yy.ravel()])
Z_poly = Z_poly.reshape(xx.shape)

plt.contourf(xx, yy, Z_poly, alpha=0.8)
plt.scatter(X[:, 0], X[:, 1], c=y, edgecolors='k', marker='o', cmap='winter')
plt.title('Clasificación con Kernel Polinómico')
plt.xlabel('Característica 1')
plt.ylabel('Característica 2')
plt.show()
\```

En este código:
- Primero, creamos un conjunto de datos no lineales utilizando la función `make_circles` de Scikit-learn.
- Luego, entrenamos dos modelos SVM, uno con un **kernel RBF** y otro con un **kernel polinómico**.
- Finalmente, visualizamos las fronteras de decisión de ambos kernels en gráficos separados.
