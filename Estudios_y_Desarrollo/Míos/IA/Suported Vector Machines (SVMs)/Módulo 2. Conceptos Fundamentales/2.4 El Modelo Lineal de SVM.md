El **modelo lineal de SVM** es la forma básica de un Support Vector Machine. En este caso, los datos son linealmente separables, lo que significa que existe un hiperplano que puede dividir las clases sin ningún error. El objetivo del modelo es encontrar este hiperplano que maximiza el margen entre las clases.

### Conceptos Clave:

- **Modelo Lineal**: El modelo intenta aprender un hiperplano que se pueda expresar de la forma \( w \cdot x + b = 0 \), donde \( w \) es el vector normal al hiperplano y \( b \) es el sesgo. La ecuación define una línea (en 2D), un plano (en 3D) o un hiperplano (en espacios de más de 3 dimensiones).
  
- **Hiperplano Óptimo**: El hiperplano óptimo es aquel que maximiza el margen entre las clases. Si el margen es grande, el modelo tiene mejor capacidad de generalización.

- **Vectores de Soporte**: Los **vectores de soporte** son los puntos más cercanos al hiperplano. Estos puntos son los que realmente definen la posición y orientación del hiperplano. Aunque todos los puntos en el conjunto de entrenamiento son importantes, solo los vectores de soporte son necesarios para definir el hiperplano.

---

### Optimización del Modelo

El proceso de encontrar el hiperplano óptimo se puede formular como un problema de **optimización convexa**. El objetivo es minimizar la norma del vector \( w \) (lo que equivale a maximizar el margen) sujeto a ciertas restricciones de clasificación. Este problema se puede resolver utilizando el método de **programación cuadrática**.

El problema de optimización es el siguiente:

$$
\text{minimizar } \frac{1}{2} \|w\|^2
$$

Sujeto a la restricción de que todas las muestras estén correctamente clasificadas:

$$
y_i (w \cdot x_i + b) \geq 1 \quad \forall i
$$

## Ejemplo de Implementación del Modelo Lineal de SVM

A continuación, se muestra cómo implementar un modelo SVM lineal utilizando la librería Scikit-learn en Python:

```python
from sklearn import datasets
from sklearn.svm import SVC
import matplotlib.pyplot as plt

# Crear un conjunto de datos de 2 características
X, y = datasets.make_classification(n_samples=100, n_features=2, n_classes=2)

# Crear un modelo SVM con kernel lineal
model = SVC(kernel='linear')

# Entrenar el modelo
model.fit(X, y)

# Obtener los coeficientes del modelo (hiperplano)
w = model.coef_[0]
b = model.intercept_

# Calcular la ecuación del hiperplano
xx = np.linspace(X[:, 0].min(), X[:, 0].max(), 30)
yy = -(w[0] * xx + b) / w[1]

# Visualizar los datos y el hiperplano
plt.scatter(X[:, 0], X[:, 1], c=y, cmap='winter')
plt.plot(xx, yy, color='red', linewidth=2)
plt.title('Modelo Lineal de SVM')
plt.xlabel('Característica 1')
plt.ylabel('Característica 2')
plt.show()
\```

En este código:
1. Creamos un conjunto de datos bidimensional con la función `make_classification`.
2. Entrenamos un modelo SVM con un kernel lineal utilizando `SVC(kernel='linear')`.
3. Calculamos la ecuación del hiperplano y lo visualizamos junto con los puntos de datos.
