La **optimización de parámetros** es una parte crucial en la implementación de modelos **Support Vector Machine (SVM)**, ya que los parámetros del modelo influencian directamente su rendimiento. En este submódulo, exploraremos cómo optimizar algunos de los parámetros más importantes de los SVMs, tales como el parámetro de regularización **C**, el **gamma** para los kernels no lineales, y el **grado** del kernel polinómico.

### 1. Parámetro C

El parámetro **C** controla el **compromiso entre un margen más amplio y la penalización por errores de clasificación**. Un valor bajo de **C** da como resultado un margen más amplio, pero puede permitir más errores en las predicciones. Un valor alto de **C** da como resultado un margen más estrecho y penaliza más los errores de clasificación.

#### Ajuste de C

La elección de **C** se puede hacer utilizando **búsqueda en cuadrícula** (Grid Search) o **búsqueda aleatoria** (Random Search) para explorar diferentes valores y determinar el que ofrezca el mejor rendimiento en los datos de prueba.

```python
from sklearn.svm import SVC
from sklearn.model_selection import GridSearchCV
import numpy as np
from sklearn.datasets import make_classification

# Crear un conjunto de datos de clasificación simple
X, y = make_classification(n_samples=100, n_features=2, n_classes=2, random_state=42)

# Definir el rango de valores para C
param_grid = {'C': [0.1, 1, 10, 100, 1000]}

# Crear un modelo SVM con kernel lineal
model = SVC(kernel='linear')

# Realizar búsqueda en cuadrícula
grid_search = GridSearchCV(model, param_grid, cv=5)
grid_search.fit(X, y)

# Mostrar el mejor parámetro C
print(f'El mejor parámetro C es: {grid_search.best_params_}')
\```

En este código:
1. Usamos `GridSearchCV` para probar diferentes valores de **C** en un modelo SVM con kernel lineal.
2. `cv=5` especifica una validación cruzada de 5 pliegues.
3. `best_params_` nos da el valor de **C** que produce el mejor rendimiento en los datos.

---

### 2. Parámetro Gamma (para kernels no lineales)

El parámetro **gamma** se usa con los **kernels no lineales**, como el **kernel RBF**. Controla la amplitud de la función de base radial, lo que afecta la flexibilidad del modelo. Un valor bajo de **gamma** produce un modelo más suave, mientras que un valor alto produce un modelo más flexible, pero puede causar sobreajuste.

#### Ajuste de Gamma

Al igual que con **C**, podemos usar **búsqueda en cuadrícula** para encontrar el valor óptimo de **gamma**.

```python
# Definir el rango de valores para gamma
param_grid_rbf = {'gamma': ['scale', 'auto', 0.1, 1, 10]}

# Crear un modelo SVM con kernel RBF
model_rbf = SVC(kernel='rbf')

# Realizar búsqueda en cuadrícula para gamma
grid_search_rbf = GridSearchCV(model_rbf, param_grid_rbf, cv=5)
grid_search_rbf.fit(X, y)

# Mostrar el mejor parámetro gamma
print(f'El mejor parámetro gamma es: {grid_search_rbf.best_params_}')
\```

En este código:
4. Usamos `GridSearchCV` para probar diferentes valores de **gamma** en un modelo SVM con kernel RBF.
5. `best_params_` nos proporciona el valor de **gamma** que ofrece el mejor rendimiento.

---

### 3. Grado del Kernel Polinómico

El parámetro **grado** se usa cuando el modelo SVM utiliza un **kernel polinómico**. Este parámetro controla el grado del polinomio utilizado en la transformación de los datos. Un grado bajo (como 2 o 3) produce un modelo más simple, mientras que un grado alto puede permitir una mayor flexibilidad y complejidad, pero también puede causar sobreajuste.

#### Ajuste del Grado

La búsqueda en cuadrícula también se puede aplicar para el parámetro **grado**.

```python
# Definir el rango de valores para grado
param_grid_poly = {'degree': [2, 3, 4, 5]}

# Crear un modelo SVM con kernel polinómico
model_poly = SVC(kernel='poly')

# Realizar búsqueda en cuadrícula para el grado
grid_search_poly = GridSearchCV(model_poly, param_grid_poly, cv=5)
grid_search_poly.fit(X, y)

# Mostrar el mejor parámetro grado
print(f'El mejor parámetro grado es: {grid_search_poly.best_params_}')
\```

En este código:
6. Usamos `GridSearchCV` para probar diferentes valores de **grado** en un modelo SVM con kernel polinómico.
7. El mejor parámetro **grado** se obtiene con `best_params_`.

---

### 4. Validación Cruzada

La **validación cruzada** es una técnica que divide los datos en varios pliegues y entrena el modelo múltiples veces, cada vez utilizando diferentes combinaciones de los pliegues como conjunto de entrenamiento y conjunto de prueba. Esto ayuda a evaluar el rendimiento del modelo de manera más robusta y a evitar el sobreajuste.

Scikit-learn ofrece la función `cross_val_score` para realizar validación cruzada de manera fácil:

```python
from sklearn.model_selection import cross_val_score

# Realizar validación cruzada para el modelo con el mejor parámetro C
scores = cross_val_score(grid_search.best_estimator_, X, y, cv=5)

# Mostrar la precisión media
print(f'Precisión media con validación cruzada: {scores.mean()}')
\```

En este código:
8. `cross_val_score` realiza validación cruzada con el modelo entrenado.
9. El rendimiento del modelo se mide utilizando la precisión media.

---

### 5. Optimización de los Hiperparámetros con RandomizedSearchCV

Si tienes un conjunto de parámetros muy grande, la **búsqueda en cuadrícula** puede ser computacionalmente costosa. En su lugar, puedes usar **RandomizedSearchCV**, que realiza una búsqueda aleatoria a través del espacio de hiperparámetros.

```python
from sklearn.model_selection import RandomizedSearchCV
import scipy.stats as stats

# Definir el rango de valores para C y gamma
param_dist = {'C': stats.uniform(0.1, 10), 'gamma': stats.uniform(0.001, 1)}

# Crear un modelo SVM con kernel RBF
model_rbf_random = SVC(kernel='rbf')

# Realizar búsqueda aleatoria
random_search = RandomizedSearchCV(model_rbf_random, param_dist, n_iter=100, cv=5, random_state=42)
random_search.fit(X, y)

# Mostrar el mejor parámetro encontrado
print(f'El mejor parámetro encontrado por búsqueda aleatoria es: {random_search.best_params_}')
\```

---

## Resumen

La optimización de parámetros es esencial para maximizar el rendimiento de un modelo **SVM**. Los pasos clave para la optimización incluyen:

10. **Ajuste de C**: Controla el trade-off entre el margen y los errores de clasificación.
11. **Ajuste de gamma**: Controla la amplitud de la función de base radial en los kernels RBF.
12. **Ajuste del grado**: Controla el grado del polinomio en el kernel polinómico.
13. **Validación cruzada**: Ayuda a evaluar el rendimiento del modelo y evita el sobreajuste.
14. **Búsqueda aleatoria**: Una alternativa eficiente a la búsqueda en cuadrícula cuando hay muchos parámetros.
