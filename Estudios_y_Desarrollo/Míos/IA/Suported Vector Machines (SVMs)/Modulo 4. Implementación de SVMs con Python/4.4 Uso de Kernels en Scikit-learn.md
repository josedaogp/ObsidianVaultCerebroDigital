Uno de los puntos fuertes de los **Support Vector Machines (SVMs)** es su capacidad para manejar problemas no lineales mediante el uso de **kernels**. Un **kernel** transforma el espacio de características de manera que sea posible encontrar un hiperplano de separación en un espacio de mayor dimensión, incluso cuando los datos no son linealmente separables en su espacio original.

En **Scikit-learn**, la clase `SVC` permite trabajar con varios tipos de kernels para resolver problemas tanto lineales como no lineales.

### Tipos de Kernels en SVM

Los tipos de kernels más comunes en SVM son:

1. **Kernel Lineal**: Se utiliza cuando los datos son lineales o pueden ser separados linealmente con un margen adecuado. Su función de kernel es simplemente el producto interno \( K(x, x') = x \cdot x' \).
   
2. **Kernel Polinómico**: Este kernel mapea los datos a un espacio de mayor dimensión, lo que permite separar los datos que no son lineales. La función de kernel polinómico es:

   $$
   K(x, x') = (x \cdot x' + c)^d
   $$

   Donde \(c\) es una constante y \(d\) es el grado del polinomio.

3. **Kernel Gaussiano (RBF - Radial Basis Function)**: Este kernel es uno de los más populares debido a su flexibilidad y capacidad para manejar datos altamente no lineales. La función de kernel gaussiano es:

   $$
   K(x, x') = \exp\left(-\frac{\|x - x'\|^2}{2\sigma^2}\right)
   $$

   Donde \(\sigma\) es un parámetro que controla la amplitud de la función de base radial.

4. **Kernel Sigmoide**: Este kernel utiliza la función sigmoide, similar a las que se utilizan en las redes neuronales:

   $$
   K(x, x') = \tanh(\alpha x \cdot x' + c)
   $$

   Donde \(\alpha\) y \(c\) son parámetros ajustables.

### Implementación de SVM con Diferentes Kernels

Vamos a implementar modelos **SVM** utilizando diferentes kernels para ver cómo afectan la clasificación en un conjunto de datos no lineales.

#### a) Kernel Lineal

Primero, creamos un modelo SVM con **kernel lineal** para un conjunto de datos linealmente separables.

```python
from sklearn.svm import SVC
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import make_classification

# Crear un conjunto de datos de clasificación simple
X, y = make_classification(n_samples=100, n_features=2, n_classes=2, random_state=42)

# Crear un modelo SVM con kernel lineal
model_linear = SVC(kernel='linear')

# Entrenar el modelo
model_linear.fit(X, y)

# Visualizar los resultados
plt.scatter(X[:, 0], X[:, 1], c=y, cmap='winter')
plt.title('SVM con Kernel Lineal')
plt.xlabel('Característica 1')
plt.ylabel('Característica 2')
plt.show()
\```

#### b) Kernel Polinómico

Ahora, probamos el **kernel polinómico**, que es útil cuando los datos no son lineales.

```python
# Crear un modelo SVM con kernel polinómico
model_poly = SVC(kernel='poly', degree=3, coef0=1)

# Entrenar el modelo
model_poly.fit(X, y)

# Visualizar los resultados
plt.scatter(X[:, 0], X[:, 1], c=y, cmap='winter')
plt.title('SVM con Kernel Polinómico')
plt.xlabel('Característica 1')
plt.ylabel('Característica 2')
plt.show()
\```

#### c) Kernel RBF (Radial Basis Function)

Finalmente, vamos a usar el **kernel RBF**, que es muy efectivo para manejar problemas altamente no lineales.

```python
# Crear un modelo SVM con kernel RBF
model_rbf = SVC(kernel='rbf', gamma='scale')

# Entrenar el modelo
model_rbf.fit(X, y)

# Visualizar los resultados
plt.scatter(X[:, 0], X[:, 1], c=y, cmap='winter')
plt.title('SVM con Kernel RBF')
plt.xlabel('Característica 1')
plt.ylabel('Característica 2')
plt.show()
\```

### Comparación de los Resultados

En los ejemplos anteriores, hemos utilizado tres tipos diferentes de kernels para entrenar el modelo SVM y visualizar los resultados. La diferencia clave entre ellos es cómo el kernel transforma el espacio de características para lograr una separación más efectiva de los datos.

- **Kernel Lineal**: Funciona bien cuando los datos son lineales o casi lineales.
- **Kernel Polinómico**: Es útil cuando los datos tienen una relación no lineal de grado más alto.
- **Kernel RBF**: Es muy flexible y puede manejar separaciones muy complejas y no lineales.
