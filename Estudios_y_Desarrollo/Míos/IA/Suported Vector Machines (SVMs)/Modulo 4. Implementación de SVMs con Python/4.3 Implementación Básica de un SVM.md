Una vez que los datos están preparados y listos, podemos proceder con la implementación de un modelo **Support Vector Machine (SVM)**. A continuación, veremos cómo entrenar un modelo SVM básico en Python utilizando **Scikit-learn**.

### 1. Creación y Entrenamiento de un Modelo SVM

En este ejemplo, utilizaremos un **SVM con kernel lineal**, que es el tipo más sencillo de SVM y se utiliza cuando los datos son linealmente separables.

```python
from sklearn.svm import SVC
from sklearn.datasets import make_classification
import matplotlib.pyplot as plt

# Crear un conjunto de datos de clasificación simple
X, y = make_classification(n_samples=100, n_features=2, n_classes=2, random_state=42)

# Crear un modelo SVM con kernel lineal
model = SVC(kernel='linear')

# Entrenar el modelo
model.fit(X, y)

# Predecir las etiquetas para el conjunto de datos
y_pred = model.predict(X)

# Visualizar los resultados
plt.scatter(X[:, 0], X[:, 1], c=y, cmap='winter')
plt.scatter(X[:, 0], X[:, 1], c=y_pred, cmap='autumn', marker='x', alpha=0.5)
plt.title('SVM con Kernel Lineal')
plt.xlabel('Característica 1')
plt.ylabel('Característica 2')
plt.show()
\```

En este código:

1. Usamos la función `make_classification()` para crear un conjunto de datos de clasificación simple con dos características (que es adecuado para la visualización en 2D).
2. Creamos un modelo de **SVM con kernel lineal** utilizando la clase `SVC(kernel='linear')`.
3. Entrenamos el modelo con el método `fit()` y realizamos predicciones con `predict()`.
4. Visualizamos los puntos de datos y sus etiquetas predichas utilizando **Matplotlib**.

### 2. Visualización de los Resultados

El gráfico generado por este código muestra los puntos de datos originales (en color **verde o rojo**) y los puntos predichos por el modelo SVM (en color **amarillo o naranja**). Los puntos etiquetados con un 'X' corresponden a las predicciones del modelo.

---

### 3. Evaluación del Modelo

Para evaluar el rendimiento del modelo, podemos usar métricas como la **precisión**, **recall**, o **F1-score**. Scikit-learn proporciona un conjunto de herramientas muy útiles para calcular estas métricas.

```python
from sklearn.metrics import accuracy_score, classification_report

# Calcular la precisión del modelo
accuracy = accuracy_score(y, y_pred)

# Generar un reporte con precisión, recall y F1-score
report = classification_report(y, y_pred)

print(f'Precisión: {accuracy}')
print('Reporte de Clasificación:')
print(report)
\```

En este código:
1. Utilizamos `accuracy_score()` para calcular la precisión del modelo, es decir, la proporción de predicciones correctas.
2. Utilizamos `classification_report()` para generar un informe detallado que incluye precisión, recall y F1-score para cada clase.

### 4. Ajuste de Parámetros

Una vez que tenemos un modelo básico SVM, podemos comenzar a ajustar varios parámetros como el parámetro de regularización **C** o el tipo de **kernel**. Un ajuste adecuado de estos parámetros puede mejorar el rendimiento del modelo, especialmente si los datos no son linealmente separables.

#### a) Ajuste del Parámetro C

El parámetro **C** controla el trade-off entre un margen más amplio y la penalización por errores de clasificación. Un valor alto de **C** puede llevar a un modelo más complejo, mientras que un valor bajo de **C** favorece un modelo más simple y generalizado.

```python
# Probar diferentes valores de C
model = SVC(kernel='linear', C=0.1)  # C bajo
model.fit(X, y)
y_pred_low_C = model.predict(X)

model = SVC(kernel='linear', C=100)  # C alto
model.fit(X, y)
y_pred_high_C = model.predict(X)

# Comparar los resultados
print(f'Precisión con C=0.1: {accuracy_score(y, y_pred_low_C)}')
print(f'Precisión con C=100: {accuracy_score(y, y_pred_high_C)}')
\```

#### b) Uso de Kernels No Lineales

Si los datos no son lineales, podemos probar con un **kernel no lineal** como el **RBF (Radial Basis Function)**. Aquí mostramos cómo usar un kernel RBF en lugar de un kernel lineal:

```python
# SVM con kernel RBF
model_rbf = SVC(kernel='rbf', gamma='scale')
model_rbf.fit(X, y)
y_pred_rbf = model_rbf.predict(X)

# Visualizar los resultados
plt.scatter(X[:, 0], X[:, 1], c=y, cmap='winter')
plt.scatter(X[:, 0], X[:, 1], c=y_pred_rbf, cmap='autumn', marker='x', alpha=0.5)
plt.title('SVM con Kernel RBF')
plt.xlabel('Característica 1')
plt.ylabel('Característica 2')
plt.show()
\```
