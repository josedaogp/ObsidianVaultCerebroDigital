En muchos casos, los datos no pueden separarse de manera lineal, lo que significa que no es posible trazar una línea o un hiperplano que divida las clases sin errores. Afortunadamente, los **SVMs no lineales** pueden manejar estos casos mediante el uso de **kernels**, que permiten mapear los datos a un espacio de características de mayor dimensión donde sí puedan ser separables linealmente.

### ¿Qué son los SVMs No Lineales?

Los **SVMs no lineales** son simplemente una extensión de los SVMs tradicionales, donde se utiliza un **kernel no lineal** para transformar los datos en un espacio de características de mayor dimensión. En ese espacio, los datos pueden ser separables por un hiperplano lineal. A pesar de que el espacio original no es linealmente separable, el uso de un kernel adecuado permite que el modelo SVM encuentre una solución eficiente.

Los tipos más comunes de kernels no lineales incluyen:

1. **Kernel Polinómico**
2. **Kernel Gaussiano (RBF - Radial Basis Function)**

A través de la **dualidad** en el SVM, podemos operar en este espacio de características elevado sin tener que calcular explícitamente las nuevas coordenadas. Esto es lo que hace que los **SVMs no lineales** sean tan poderosos.

---

### Implementación de un SVM No Lineal con Kernel RBF

El **kernel RBF (Radial Basis Function)** es uno de los más utilizados en SVMs no lineales debido a su capacidad para manejar casos de separación compleja. A continuación, mostramos cómo implementar un **SVM no lineal** utilizando el kernel RBF.

```python
from sklearn.svm import SVC
import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import make_circles

# Crear un conjunto de datos no lineales
X, y = make_circles(n_samples=100, factor=0.5, noise=0.1)

# Crear un modelo SVM con kernel RBF
model_rbf = SVC(kernel='rbf', gamma='scale')

# Entrenar el modelo
model_rbf.fit(X, y)

# Predecir las etiquetas para el conjunto de datos
y_pred = model_rbf.predict(X)

# Visualizar los resultados
plt.scatter(X[:, 0], X[:, 1], c=y_pred, cmap='winter')
plt.title('SVM con Kernel RBF')
plt.xlabel('Característica 1')
plt.ylabel('Característica 2')
plt.show()
\```

En este código:

1. Usamos la función `make_circles()` para crear un conjunto de datos no lineales con forma de círculos, lo cual es adecuado para demostrar la capacidad de los SVMs no lineales.
2. Creamos un modelo **SVM con kernel RBF** utilizando `SVC(kernel='rbf')`.
3. Entrenamos el modelo y visualizamos cómo predice las clases en el conjunto de datos.

---

### Ajuste de los Parámetros de Kernel RBF

El parámetro **gamma** del kernel RBF controla la amplitud de la función de base radial. Un valor bajo de **gamma** produce un modelo más suave, mientras que un valor alto genera un modelo más flexible, pero puede causar **sobreajuste**.

#### Ajuste de Gamma

Al igual que en la optimización de otros parámetros, podemos usar **búsqueda en cuadrícula** para encontrar el valor óptimo de **gamma**.

```python
from sklearn.model_selection import GridSearchCV

# Definir el rango de valores para gamma
param_grid = {'gamma': ['scale', 'auto', 0.1, 1, 10]}

# Crear un modelo SVM con kernel RBF
model_rbf = SVC(kernel='rbf')

# Realizar búsqueda en cuadrícula
grid_search_rbf = GridSearchCV(model_rbf, param_grid, cv=5)
grid_search_rbf.fit(X, y)

# Mostrar el mejor parámetro gamma
print(f'El mejor parámetro gamma es: {grid_search_rbf.best_params_}')
\```

En este código:

4. Usamos `GridSearchCV` para probar diferentes valores de **gamma** en el modelo SVM con kernel RBF.
5. `best_params_` devuelve el valor óptimo de **gamma** encontrado durante la búsqueda.

### Visualización de las Fronteras de Decisión en SVM No Lineales

Una de las características más interesantes de los SVMs no lineales es cómo se ajustan a datos no lineales y encuentran fronteras de decisión complejas. A continuación, visualizamos las fronteras de decisión en un conjunto de datos no lineal utilizando un kernel RBF.

```python
# Crear una malla de puntos para visualizar las fronteras de decisión
xx, yy = np.meshgrid(np.linspace(X[:, 0].min(), X[:, 0].max(), 100),
                     np.linspace(X[:, 1].min(), X[:, 1].max(), 100))

# Realizar predicciones para todos los puntos en la malla
Z = model_rbf.predict(np.c_[xx.ravel(), yy.ravel()])
Z = Z.reshape(xx.shape)

# Visualizar las fronteras de decisión
plt.contourf(xx, yy, Z, alpha=0.8, cmap='winter')
plt.scatter(X[:, 0], X[:, 1], c=y, cmap='autumn')
plt.title('Fronteras de Decisión SVM con Kernel RBF')
plt.xlabel('Característica 1')
plt.ylabel('Característica 2')
plt.show()
\```

En este código:

6. Creamos una malla de puntos en el espacio de características para visualizar las fronteras de decisión.
7. Usamos el modelo SVM con kernel RBF para hacer predicciones sobre todos los puntos de la malla.
8. Visualizamos las fronteras de decisión junto con los puntos de datos originales.
