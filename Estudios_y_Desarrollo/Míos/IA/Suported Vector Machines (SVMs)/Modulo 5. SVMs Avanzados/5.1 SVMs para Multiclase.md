En los ejemplos anteriores, hemos trabajado con **problemas de clasificación binaria**, donde solo hay dos clases. Sin embargo, en muchos problemas reales, los datos pueden tener más de dos clases. Afortunadamente, **Scikit-learn** permite fácilmente aplicar **SVMs para problemas multiclase**.

### Enfoque de SVM para Multiclase

El algoritmo **SVM** es originalmente diseñado para problemas de clasificación binaria, pero se puede adaptar para clasificación multiclase utilizando dos enfoques principales:

1. **One-vs-Rest (OvR)**: En este enfoque, se entrena un clasificador SVM para cada clase. Cada clasificador SVM intenta separar una clase de todas las demás clases. Cuando un nuevo dato es clasificado, cada clasificador "vota" por su clase, y la clase que reciba más votos es la que se asigna.

2. **One-vs-One (OvO)**: En este enfoque, se entrenan clasificadores SVM para cada par de clases. Cada clasificador SVM intenta separar dos clases, y cuando un nuevo dato es clasificado, el clasificador más votado entre todos los clasificadores es el que determina la clase asignada.

En **Scikit-learn**, el enfoque por defecto para multiclase es **One-vs-Rest**.

---

### Implementación de un SVM Multiclase

A continuación, mostramos cómo usar un **SVM multiclase** con un conjunto de datos de ejemplo que tiene más de dos clases.

```python
from sklearn.svm import SVC
from sklearn.datasets import load_iris
import matplotlib.pyplot as plt

# Cargar el conjunto de datos Iris (tres clases)
data = load_iris()
X, y = data.data, data.target

# Crear un modelo SVM con kernel lineal para clasificación multiclase
model = SVC(kernel='linear', decision_function_shape='ovr')

# Entrenar el modelo
model.fit(X, y)

# Predecir las etiquetas para el conjunto de datos
y_pred = model.predict(X)

# Visualizar las predicciones
plt.scatter(X[:, 0], X[:, 1], c=y_pred, cmap='winter')
plt.title('SVM Multiclase (One-vs-Rest)')
plt.xlabel('Característica 1')
plt.ylabel('Característica 2')
plt.show()
\```

En este código:

1. Cargamos el **conjunto de datos Iris**, que tiene 3 clases.
2. Creamos un modelo **SVM con kernel lineal** utilizando el enfoque **One-vs-Rest** (especificado con `decision_function_shape='ovr'`).
3. Entrenamos el modelo y realizamos predicciones sobre los datos.
4. Visualizamos los resultados en un gráfico de dispersión.

---

### Ajuste de los Hiperparámetros para Multiclase

Cuando trabajas con problemas multiclase, el ajuste de parámetros como **C** y **gamma** es igual de importante que en problemas binarios. Se puede aplicar **búsqueda en cuadrícula** (Grid Search) o **búsqueda aleatoria** (Random Search) para encontrar la mejor combinación de parámetros para un modelo multiclase.

```python
from sklearn.model_selection import GridSearchCV

# Definir el rango de valores para C y gamma
param_grid = {'C': [0.1, 1, 10], 'gamma': ['scale', 'auto']}

# Crear un modelo SVM con kernel RBF
model_rbf = SVC(kernel='rbf', decision_function_shape='ovr')

# Realizar búsqueda en cuadrícula
grid_search = GridSearchCV(model_rbf, param_grid, cv=5)
grid_search.fit(X, y)

# Mostrar el mejor parámetro encontrado
print(f'El mejor parámetro encontrado por búsqueda en cuadrícula es: {grid_search.best_params_}')
\```

En este código:

1. Usamos `GridSearchCV` para probar diferentes valores de **C** y **gamma**.
2. El mejor conjunto de parámetros se selecciona a través de validación cruzada de 5 pliegues.

---

### Evaluación de un SVM Multiclase

La evaluación de un modelo **SVM multiclase** se realiza utilizando las mismas métricas que para clasificación binaria, como **precisión**, **recall**, y **F1-score**. Sin embargo, en clasificación multiclase, estas métricas se calculan para cada clase y luego se promedian.

```python
from sklearn.metrics import classification_report

# Mostrar un reporte de clasificación detallado
print(classification_report(y, y_pred))
\```

Este código genera un informe que muestra la **precisión**, **recall** y **F1-score** para cada clase en el problema multiclase.

---

### Visualización de la Frontera de Decisión para Multiclase

Visualizar las fronteras de decisión para problemas multiclase puede ser complicado si tienes más de dos características, pero se puede hacer si reducimos las dimensiones del conjunto de datos a dos utilizando técnicas como **PCA** (Análisis de Componentes Principales) o **t-SNE** (t-Distributed Stochastic Neighbor Embedding).

```python
from sklearn.decomposition import PCA

# Reducir las características a dos dimensiones usando PCA
pca = PCA(n_components=2)
X_reduced = pca.fit_transform(X)

# Entrenar un modelo SVM con kernel RBF
model_rbf.fit(X_reduced, y)
y_pred_reduced = model_rbf.predict(X_reduced)

# Visualizar las fronteras de decisión
plt.scatter(X_reduced[:, 0], X_reduced[:, 1], c=y_pred_reduced, cmap='winter')
plt.title('SVM Multiclase con PCA')
plt.xlabel('Componente Principal 1')
plt.ylabel('Componente Principal 2')
plt.show()
\```

Este código utiliza **PCA** para reducir el número de dimensiones a dos y luego entrena un modelo SVM multiclase en este espacio reducido. La visualización de las fronteras de decisión es mucho más sencilla en un espacio bidimensional.
