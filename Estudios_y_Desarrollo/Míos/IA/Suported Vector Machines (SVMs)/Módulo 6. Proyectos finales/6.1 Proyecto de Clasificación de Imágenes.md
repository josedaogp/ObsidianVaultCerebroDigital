## 6.1 Proyecto de Clasificación de Imágenes

En este submódulo, aplicaremos lo aprendido sobre **SVMs** a un caso real: la **clasificación de imágenes**. La clasificación de imágenes es uno de los problemas más comunes en **aprendizaje automático**, y SVMs son particularmente efectivos para ello, especialmente cuando las imágenes están en un formato que se puede transformar en un espacio de características adecuado.

### Objetivo del Proyecto

Nuestro objetivo es entrenar un modelo **SVM** para clasificar imágenes en diferentes categorías. Usaremos el **conjunto de datos de dígitos** de **Scikit-learn**, que es un conjunto de datos clásico utilizado para la clasificación de imágenes de dígitos escritos a mano (0-9). Estas imágenes están representadas en formato **32x32 píxeles** y cada imagen es etiquetada con el dígito que representa.

---

### 1. Cargar y Preprocesar los Datos

Primero, vamos a cargar el conjunto de datos de dígitos y preparar los datos para el modelo SVM. Cada imagen será convertida en un vector de características y las etiquetas estarán representadas por los dígitos correspondientes.

```python
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
from sklearn.svm import SVC
import matplotlib.pyplot as plt

# Cargar el conjunto de datos de dígitos
digits = load_digits()

# Características (X) y etiquetas (y)
X, y = digits.data, digits.target

# Dividir los datos en entrenamiento y prueba
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Visualizar algunas imágenes de los dígitos
fig, axes = plt.subplots(1, 5, figsize=(10, 3))
for i, ax in enumerate(axes):
    ax.imshow(X[i].reshape(8, 8), cmap='gray')
    ax.set_title(f'Dígito: {y[i]}')
plt.show()
\```

En este código:
1. Usamos `load_digits()` para cargar el conjunto de datos de dígitos de **Scikit-learn**.
2. Dividimos los datos en conjuntos de entrenamiento y prueba con `train_test_split()`.
3. Visualizamos las primeras 5 imágenes de dígitos para entender cómo se ve el conjunto de datos.

---

### 2. Entrenar el Modelo SVM

Una vez que los datos están listos, podemos entrenar un modelo **SVM con kernel RBF** para clasificar las imágenes.

```python
# Crear un modelo SVM con kernel RBF
model = SVC(kernel='rbf', gamma='scale', C=1)

# Entrenar el modelo
model.fit(X_train, y_train)

# Evaluar el modelo
accuracy = model.score(X_test, y_test)
print(f'Precisión del modelo SVM: {accuracy * 100:.2f}%')
\```

En este código:
4. Usamos un **SVM con kernel RBF** para entrenar el modelo.
5. Entrenamos el modelo con `fit()` usando el conjunto de entrenamiento.
6. Evaluamos el modelo con `score()` utilizando el conjunto de prueba.

---

### 3. Evaluación del Modelo

Para evaluar el rendimiento del modelo, podemos usar un reporte de clasificación con métricas como **precisión**, **recall**, y **F1-score**.

```python
from sklearn.metrics import classification_report

# Predecir las etiquetas en el conjunto de prueba
y_pred = model.predict(X_test)

# Mostrar el reporte de clasificación
print('Reporte de clasificación:')
print(classification_report(y_test, y_pred))
\```

Este código:
7. Predice las etiquetas para las imágenes en el conjunto de prueba.
8. Genera un **reporte de clasificación** que muestra las métricas de rendimiento para cada clase (dígito).

---

### 4. Visualización de las Predicciones

Finalmente, visualizamos algunas imágenes de prueba junto con sus predicciones para ver cómo el modelo ha clasificado las imágenes.

```python
# Visualizar algunas imágenes de prueba junto con las predicciones
fig, axes = plt.subplots(1, 5, figsize=(10, 3))
for i, ax in enumerate(axes):
    ax.imshow(X_test[i].reshape(8, 8), cmap='gray')
    ax.set_title(f'Predicción: {y_pred[i]}')
plt.show()
\```

Este código muestra cómo el modelo ha clasificado algunas imágenes del conjunto de prueba, comparando las imágenes con las predicciones.

---

## 5. Optimización y Ajuste del Modelo

Después de entrenar el modelo básico, es probable que queramos optimizar los parámetros **C** y **gamma** para mejorar el rendimiento del modelo. Usaremos **búsqueda en cuadrícula** para encontrar los mejores valores de estos parámetros.

```python
from sklearn.model_selection import GridSearchCV

# Definir los parámetros a ajustar
param_grid = {'C': [0.1, 1, 10, 100], 'gamma': ['scale', 'auto', 0.1, 1]}

# Realizar la búsqueda en cuadrícula
grid_search = GridSearchCV(SVC(kernel='rbf'), param_grid, cv=5)
grid_search.fit(X_train, y_train)

# Mostrar los mejores parámetros encontrados
print(f'Los mejores parámetros son: {grid_search.best_params_}')

# Evaluar el modelo optimizado
best_model = grid_search.best_estimator_
optimized_accuracy = best_model.score(X_test, y_test)
print(f'Precisión del modelo optimizado: {optimized_accuracy * 100:.2f}%')
\```

En este código:
9. Usamos `GridSearchCV` para encontrar los mejores valores de **C** y **gamma**.
10. Entrenamos el modelo con los parámetros optimizados y evaluamos su rendimiento.
