En este submódulo, vamos a aplicar **SVMs** a un caso práctico de **clasificación de texto**. Este es un problema muy común en el campo del procesamiento de lenguaje natural (NLP). Los **SVMs** son muy efectivos para tareas como la clasificación de correos electrónicos (spam vs. no spam) o la clasificación de opiniones (positivas vs. negativas), especialmente cuando los datos están representados de manera adecuada.

### Objetivo del Proyecto

Nuestro objetivo es entrenar un modelo **SVM** para clasificar **textos** en diferentes categorías. Usaremos el conjunto de datos **20 Newsgroups**, que contiene una colección de documentos de noticias de 20 categorías diferentes. Cada documento es una noticia, y la tarea consiste en clasificar cada documento en su categoría correspondiente.

---

### 1. Cargar y Preprocesar los Datos

Primero, cargamos el conjunto de datos **20 Newsgroups**. Este conjunto de datos contiene 20 categorías de noticias diferentes, y cada documento está etiquetado con su categoría correspondiente.

```python
from sklearn.datasets import fetch_20newsgroups
from sklearn.model_selection import train_test_split
from sklearn.feature_extraction.text import TfidfVectorizer

# Cargar el conjunto de datos 20 Newsgroups
newsgroups = fetch_20newsgroups(subset='all')

# Características (X) y etiquetas (y)
X, y = newsgroups.data, newsgroups.target

# Dividir los datos en entrenamiento y prueba
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# Usar TF-IDF para convertir los textos a vectores de características
vectorizer = TfidfVectorizer(stop_words='english')
X_train_tfidf = vectorizer.fit_transform(X_train)
X_test_tfidf = vectorizer.transform(X_test)

# Ver algunas de las características extraídas
print(f'Número de características (palabras) extraídas: {X_train_tfidf.shape[1]}')
\```

En este código:
1. Usamos `fetch_20newsgroups` para cargar el conjunto de datos **20 Newsgroups**.
2. Dividimos los datos en conjuntos de entrenamiento y prueba con `train_test_split()`.
3. Usamos **TF-IDF** para convertir los textos en vectores de características. Esto convierte las palabras en números, donde las palabras más relevantes para cada documento tienen más peso.

---

### 2. Entrenar el Modelo SVM

Una vez que los textos están convertidos en vectores de características, podemos entrenar un modelo **SVM** para la clasificación.

```python
from sklearn.svm import SVC

# Crear un modelo SVM con kernel lineal
model = SVC(kernel='linear')

# Entrenar el modelo
model.fit(X_train_tfidf, y_train)

# Evaluar el modelo
accuracy = model.score(X_test_tfidf, y_test)
print(f'Precisión del modelo SVM: {accuracy * 100:.2f}%')
\```

En este código:
4. Usamos un modelo **SVM con kernel lineal** para la clasificación de texto.
5. Entrenamos el modelo con `fit()` usando los vectores de características de entrenamiento.
6. Evaluamos el modelo con `score()` utilizando el conjunto de prueba.

---

### 3. Evaluación del Modelo

Para evaluar el rendimiento del modelo, usamos métricas como **precisión**, **recall**, y **F1-score**. El reporte de clasificación nos da una visión más detallada de cómo está funcionando el modelo en cada categoría.

```python
from sklearn.metrics import classification_report

# Predecir las etiquetas en el conjunto de prueba
y_pred = model.predict(X_test_tfidf)

# Mostrar el reporte de clasificación
print('Reporte de clasificación:')
print(classification_report(y_test, y_pred, target_names=newsgroups.target_names))
\```

Este código:
7. Usa `predict()` para hacer predicciones sobre el conjunto de prueba.
8. Genera un **reporte de clasificación** que muestra métricas como precisión, recall y F1-score para cada clase (categoría de noticia).

---

### 4. Optimización del Modelo

El rendimiento del modelo puede mejorarse ajustando los hiperparámetros **C** (para regularización) y el tipo de kernel. Usamos **búsqueda en cuadrícula** para encontrar la mejor combinación de estos parámetros.

```python
from sklearn.model_selection import GridSearchCV

# Definir los parámetros a ajustar
param_grid = {'C': [0.1, 1, 10, 100], 'kernel': ['linear', 'rbf']}

# Realizar búsqueda en cuadrícula
grid_search = GridSearchCV(SVC(), param_grid, cv=5)
grid_search.fit(X_train_tfidf, y_train)

# Mostrar los mejores parámetros encontrados
print(f'Los mejores parámetros son: {grid_search.best_params_}')

# Evaluar el modelo optimizado
best_model = grid_search.best_estimator_
optimized_accuracy = best_model.score(X_test_tfidf, y_test)
print(f'Precisión del modelo optimizado: {optimized_accuracy * 100:.2f}%')
\```

En este código:
9. Usamos `GridSearchCV` para ajustar los hiperparámetros **C** y **kernel**.
10. `best_params_` nos devuelve la mejor combinación de parámetros encontrados durante la búsqueda en cuadrícula.

---

### 5. Visualización de Resultados

Aunque la visualización de los resultados de un modelo de texto puede ser más difícil debido a la naturaleza no visual de los datos, podemos mostrar algunas de las predicciones para obtener una idea de cómo está funcionando el modelo.

```python
# Mostrar algunas predicciones junto con las verdaderas etiquetas
for i in range(5):

Este código muestra algunos ejemplos de predicciones junto con las etiquetas verdaderas para evaluar cómo el modelo clasifica los textos.
