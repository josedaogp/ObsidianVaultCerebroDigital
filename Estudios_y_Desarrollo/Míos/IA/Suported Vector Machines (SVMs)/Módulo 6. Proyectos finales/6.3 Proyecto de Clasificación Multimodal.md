En este submódulo, abordaremos un **proyecto de clasificación multimodal**, donde los datos provienen de múltiples fuentes o tipos, como imágenes y texto. Este tipo de proyecto es común en situaciones del mundo real, como en la clasificación de reseñas de productos que contienen tanto imágenes como texto, o en la clasificación de contenido multimedia como videos, que incluyen imágenes, texto y audio.

### Objetivo del Proyecto

El objetivo es entrenar un modelo de **SVM multimodal** que pueda combinar **imágenes** y **texto** para realizar una tarea de clasificación. Usaremos un conjunto de datos que contiene tanto imágenes como descripciones textuales para predecir las categorías de los productos.

---

### 1. Cargar y Preprocesar los Datos

Primero, necesitamos cargar un conjunto de datos multimodal. Para este ejemplo, supondremos que tenemos un conjunto de datos que contiene tanto imágenes como texto. En la práctica, puedes usar conjuntos de datos como **MSCOCO** o **Flickr8k**, que contienen tanto imágenes como descripciones de texto.

#### Cargar las imágenes

Vamos a usar un conjunto de datos de imágenes y sus correspondientes etiquetas. Usaremos **CIFAR-10** como ejemplo, que es un conjunto de datos de 60,000 imágenes en 10 clases.

```python
from sklearn.datasets import fetch_openml
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
import numpy as np

# Cargar el conjunto de datos de CIFAR-10
cifar10 = fetch_openml('cifar_10', version=1)

# Características (X) y etiquetas (y)
X_images, y = cifar10.data, cifar10.target

# Normalizar las características de las imágenes
scaler = StandardScaler()
X_images_scaled = scaler.fit_transform(X_images)

# Dividir los datos en entrenamiento y prueba
X_train, X_test, y_train, y_test = train_test_split(X_images_scaled, y, test_size=0.3, random_state=42)

# Ver el número de características de las imágenes
print(f'Número de características de las imágenes: {X_train.shape[1]}')
\```

Este código carga el conjunto de datos CIFAR-10 y escala las características de las imágenes para prepararlas para el modelo SVM.

#### Cargar el texto asociado a las imágenes

Imaginemos que cada imagen tiene una descripción textual asociada, y que estas descripciones están en un archivo de texto. Cargamos y preprocesamos las descripciones textuales utilizando **TF-IDF**.

```python
from sklearn.feature_extraction.text import TfidfVectorizer

# Supongamos que tenemos descripciones textuales para cada imagen
# Para simplificar, generamos descripciones ficticias
descriptions = ['Esta es una imagen de un perro' for _ in range(X_train.shape[0])]

# Convertir las descripciones de texto en vectores de características utilizando TF-IDF
vectorizer = TfidfVectorizer(stop_words='english')
X_text = vectorizer.fit_transform(descriptions)

# Ver el número de características extraídas del texto
print(f'Número de características del texto: {X_text.shape[1]}')
\```

Este código convierte las descripciones textuales en vectores utilizando **TF-IDF**.

---

### 2. Combinar las Características de Imagen y Texto

Una vez que hemos preprocesado tanto las imágenes como el texto, necesitamos combinarlos en un solo conjunto de características. Podemos hacerlo mediante **concatenación** de las características de las imágenes y del texto.

```python
from scipy.sparse import hstack

# Combinar las características de las imágenes y el texto
X_combined = hstack([X_train, X_text])

# Combinamos también los datos de prueba
X_test_combined = hstack([X_test, vectorizer.transform(descriptions)])
\`

Aquí estamos utilizando **`hstack`** de **SciPy** para concatenar las matrices dispersas de características de imágenes y texto. El resultado es un conjunto de datos combinado que contiene tanto las características visuales como las textuales.

---

### 3. Entrenar el Modelo SVM Multimodal

Ahora podemos entrenar el modelo **SVM** usando las características combinadas de imágenes y texto. Utilizamos un modelo **SVM con kernel RBF** para manejar la complejidad de los datos.

\```python
from sklearn.svm import SVC

# Crear el modelo SVM con kernel RBF
model = SVC(kernel='rbf', gamma='scale', C=1)

# Entrenar el modelo con las características combinadas
model.fit(X_combined, y_train)

# Evaluar el modelo con el conjunto de prueba
accuracy = model.score(X_test_combined, y_test)
print(f'Precisión del modelo multimodal: {accuracy * 100:.2f}%')
\```

En este código:
1. Creamos un modelo **SVM con kernel RBF**.
2. Entrenamos el modelo utilizando las características combinadas de las imágenes y el texto.
3. Evaluamos la precisión del modelo en el conjunto de prueba.

---

### 4. Evaluación del Modelo

Como en los proyectos anteriores, evaluamos el modelo utilizando métricas como **precisión**, **recall**, y **F1-score**.

```python
from sklearn.metrics import classification_report

# Predecir las etiquetas en el conjunto de prueba
y_pred = model.predict(X_test_combined)

# Mostrar el reporte de clasificación
print('Reporte de clasificación:')
print(classification_report(y_test, y_pred))
\```

Este código genera un **reporte de clasificación** que nos da detalles sobre el rendimiento del modelo en cada clase.

---

### 5. Visualización de Predicciones

Podemos visualizar algunas de las imágenes de prueba junto con las predicciones del modelo para obtener una mejor comprensión de su rendimiento.

```python
import matplotlib.pyplot as plt

# Mostrar algunas predicciones junto con las verdaderas etiquetas
fig, axes = plt.subplots(1, 5, figsize=(15, 5))
for i, ax in enumerate(axes):
    ax.imshow(X_test[i].reshape(32, 32, 3))  # Reshape de la imagen CIFAR-10
    ax.set_title(f'Predicción: {y_pred[i]}')
    ax.axis('off')

plt.show()
\```

Este código muestra algunas de las imágenes de prueba junto con sus predicciones del modelo. Las imágenes son reconfiguradas a su tamaño original (32x32 píxeles) para la visualización.
