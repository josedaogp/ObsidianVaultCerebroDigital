#### Resumen del Módulo 1

- Las CNNs son redes neuronales especializadas en el procesamiento de imágenes.
- Usan filtros para extraer características y pooling para reducir la dimensionalidad.
- Tienen capas como Convolución, Pooling y Completamente Conectadas que permiten la clasificación de imágenes.

---

**Ejercicio Propuesto**:

1. Implementa una pequeña red neuronal convolucional para la clasificación de imágenes usando un conjunto de datos simple como **MNIST** (dígitos escritos a mano).
2. Explora cómo se comportan las imágenes después de aplicar convolución y pooling. ¿Qué cambios observas en las imágenes?

```python
from keras.models import Sequential
from keras.layers import Conv2D, MaxPooling2D, Flatten, Dense

# Crear el modelo
model = Sequential()

# Capa de convolución
model.add(Conv2D(32, (3, 3), activation='relu', input_shape=(28, 28, 1)))

# Capa de pooling
model.add(MaxPooling2D(pool_size=(2, 2)))

# Aplanar los datos
model.add(Flatten())

# Capa completamente conectada
model.add(Dense(128, activation='relu'))
model.add(Dense(10, activation='softmax'))

# Compilar el modelo
model.compile(optimizer='adam', loss='categorical_crossentropy', metrics=['accuracy'])

# Resumen del modelo
model.summary()

```
