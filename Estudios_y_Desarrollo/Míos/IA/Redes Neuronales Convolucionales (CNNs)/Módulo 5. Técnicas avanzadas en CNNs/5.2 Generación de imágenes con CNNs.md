### Introducción

En este submódulo, exploraremos dos técnicas avanzadas de redes neuronales que tienen la capacidad de generar nuevas imágenes. Estas técnicas no solo sirven para la clasificación de imágenes, sino que también permiten crear imágenes completamente nuevas basadas en un conjunto de datos de entrada. Vamos a estudiar las Redes Generativas Antagónicas (GANs) y los Autoencoders, dos de las herramientas más poderosas para la generación de imágenes.

### 1. **Redes Generativas Antagónicas (GANs)**

Las GANs son un tipo de red neuronal que consta de dos redes: el generador y el discriminador. El generador crea imágenes falsas que intentan imitar las imágenes reales, mientras que el discriminador evalúa si una imagen es real o generada. El objetivo es que el generador se vuelva tan bueno que el discriminador no pueda distinguir entre imágenes reales y generadas. Este proceso se conoce como "juego de suma cero", donde el generador y el discriminador compiten entre sí.

#### 1.1. **Arquitectura de las GANs**

La arquitectura de las GANs se compone de dos redes:
- **Generador**: Crea imágenes falsas a partir de ruido aleatorio. Se puede pensar en el generador como un "artista" que intenta crear una pintura que parezca lo más realista posible.
- **Discriminador**: Evalúa las imágenes y decide si son reales o generadas. Es como un "crítico de arte" que juzga la autenticidad de las obras.

#### 1.2. **Fórmulas de las GANs**

La función de pérdida de una GAN se define como:

$$
\mathcal{L}_D = -\mathbb{E}_{x \sim p_{\text{data}}(x)}[\log D(x)] - \mathbb{E}_{z \sim p_{\text{z}}(z)}[\log(1 - D(G(z)))]
$$

$$
\mathcal{L}_G = -\mathbb{E}_{z \sim p_{\text{z}}(z)}[\log D(G(z))]
$$

Donde:
- $D(x)$ es la probabilidad de que la imagen $x$ sea real, según el discriminador.
- $G(z)$ es la imagen generada por el generador a partir de un vector de ruido $z$.
- $p_{\text{data}}(x)$ es la distribución de las imágenes reales.

**Símil**: Imagina una competencia entre un artista y un crítico de arte. El artista intenta hacer una obra tan convincente que el crítico no pueda notar que es falsa. A medida que el tiempo pasa, el artista mejora, y el crítico se vuelve más exigente.

#### 1.3. **Aplicaciones de las GANs**
Las GANs tienen aplicaciones muy poderosas, tales como:
- **Generación de imágenes realistas**: Crear imágenes de alta calidad de personas, paisajes, o animales que no existen.
- **Mejoramiento de imágenes**: Aumentar la resolución o calidad de imágenes.
- **Transferencia de estilo**: Aplicar el estilo de un artista a una imagen sin perder su contenido.

### 2. **Autoencoders**

Un autoencoder es una red neuronal utilizada para aprender una representación eficiente (codificación) de un conjunto de datos, típicamente con el fin de reducción de dimensionalidad. El autoencoder tiene dos partes principales:

- **Codificador (Encoder)**: Reduce la dimensionalidad de la entrada.
- **Decodificador (Decoder)**: Reconstruye la entrada original a partir de la representación comprimida.

#### 2.1. **Arquitectura de un Autoencoder**

El proceso de un autoencoder es el siguiente:

- Se alimenta una imagen a la red.
- El codificador reduce la imagen a una representación de tamaño más pequeño (la codificación).
- El decodificador toma la codificación y reconstruye la imagen original.

#### 2.2. **Fórmula del Autoencoder**

El objetivo de un autoencoder es minimizar la pérdida de reconstrucción entre la entrada y la salida. La función de pérdida comúnmente utilizada es el error cuadrático medio (MSE):
$$L=N1​i=1∑N​(xi​−x^i​)2$$Donde:

- $x_i$ es el valor de la entrada original.
- $\hat{x}_i$ es el valor de la entrada reconstruida.

**Símil**: Imagina que un artista toma una foto de una ciudad y la reduce a un boceto simplificado (codificación). Luego, otro artista trata de reconstruir la foto a partir de ese boceto (decodificación). El objetivo es que la reconstrucción sea lo más parecida posible a la foto original.

#### 2.3. **Aplicaciones de los Autoencoders**

Los autoencoders tienen muchas aplicaciones en generación de imágenes y procesamiento de datos:

- **Reducción de dimensionalidad**: Usado para representar imágenes complejas en un espacio más pequeño.
- **Generación de imágenes**: Similar a las GANs, pueden generar imágenes a partir de datos comprimidos.
- **Análisis de anomalías**: Detectar anomalías al ver si una imagen se puede reconstruir correctamente.

#### 2.4. **Ejemplo de Autoencoder en Keras**
```python
from tensorflow.keras.models import Model
from tensorflow.keras.layers import Input, Dense, Flatten, Reshape
from tensorflow.keras import regularizers

# Codificador
input_img = Input(shape=(28, 28, 1))
x = Flatten()(input_img)
x = Dense(128, activation='relu')(x)
encoded = Dense(32, activation='relu')(x)

# Decodificador
x = Dense(128, activation='relu')(encoded)
x = Dense(28 * 28 * 1, activation='sigmoid')(x)
decoded = Reshape((28, 28, 1))(x)

# Autoencoder
autoencoder = Model(input_img, decoded)

# Compilación
autoencoder.compile(optimizer='adam', loss='mse')

# Resumen del modelo
autoencoder.summary()

```
Este es un autoencoder simple que puede utilizarse para la reconstrucción de imágenes de 28x28 píxeles. Se utiliza una función de pérdida MSE para asegurar que la imagen reconstruida sea lo más similar posible a la original.
