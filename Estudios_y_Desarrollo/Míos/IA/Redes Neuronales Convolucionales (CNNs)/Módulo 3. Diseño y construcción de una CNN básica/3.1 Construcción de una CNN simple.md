En este submódulo vamos a construir una red neuronal convolucional simple para la clasificación de imágenes. Usaremos **Keras**, una API de alto nivel para crear modelos de redes neuronales, que está integrada en TensorFlow.

##### **Arquitectura de una CNN básica**

Una arquitectura de CNN típica puede consistir en las siguientes capas:

1. **Capa de Convolución (Conv2D)**: Para extraer características locales de la imagen.
2. **Capa de Pooling (MaxPooling)**: Para reducir la dimensionalidad y hacer que el modelo sea más eficiente.
3. **Capa de Aplanamiento (Flatten)**: Para convertir las salidas de las capas convolucionales en una forma que se pueda pasar a las capas completamente conectadas.
4. **Capa Completamente Conectada (Dense)**: Para clasificar las características extraídas por las capas anteriores.
5. **Capa de Salida (Softmax)**: Para obtener las probabilidades de las clases.

La arquitectura básica de la CNN será:

- **Convolución** → **Pooling** → **Flatten** → **Fully Connected**

##### **Código en Keras (construcción básica)**
```python
from keras.models import Sequential
from keras.layers import Conv2D, MaxPooling2D, Flatten, Dense

# Crear el modelo
model = Sequential()

# Capa de convolución
model.add(Conv2D(32, (3, 3), activation='relu', input_shape=(28, 28, 1)))

# Capa de pooling
model.add(MaxPooling2D(pool_size=(2, 2)))

# Aplanar los datos
model.add(Flatten())

# Capa completamente conectada
model.add(Dense(128, activation='relu'))
model.add(Dense(10, activation='softmax'))

# Compilar el modelo
model.compile(optimizer='adam', loss='categorical_crossentropy', metrics=['accuracy'])

# Resumen del modelo
model.summary()

```
Este código crea una red simple para clasificación de imágenes de **28x28 píxeles** (como las del conjunto de datos **MNIST**).

##### **Explicación del código**:

1. **Conv2D(32, (3, 3), activation='relu')**: Esta capa aplica 32 filtros de tamaño 3x3 a la imagen de entrada. La función de activación **ReLU** se aplica a la salida de la convolución.
2. **MaxPooling2D(pool_size=(2, 2))**: Esta capa realiza un Max Pooling con una ventana de 2x2, reduciendo la resolución de la imagen.
3. **Flatten()**: Esta capa aplana las salidas de la capa de pooling para que puedan ser alimentadas a una capa densa.
4. **Dense(128, activation='relu')**: Capa completamente conectada con 128 neuronas y activación ReLU.
5. **Dense(10, activation='softmax')**: Capa de salida con 10 neuronas (para 10 clases) y activación **softmax**, que convierte los valores en probabilidades.

##### **Entrenamiento básico de la CNN**

Una vez que hemos construido el modelo, el siguiente paso es **entrenarlo** utilizando un conjunto de datos. En este caso, vamos a usar **MNIST**, que es un conjunto de datos de imágenes de dígitos escritos a mano.
```python
from keras.datasets import mnist
from keras.utils import to_categorical

# Cargar el conjunto de datos MNIST
(x_train, y_train), (x_test, y_test) = mnist.load_data()

# Normalizar los datos (pasarlos de [0,255] a [0,1])
x_train = x_train.astype('float32') / 255
x_test = x_test.astype('float32') / 255

# Redimensionar los datos de entrada para que tengan la forma correcta (28x28x1)
x_train = x_train.reshape(-1, 28, 28, 1)
x_test = x_test.reshape(-1, 28, 28, 1)

# Convertir las etiquetas a formato one-hot (vector binario)
y_train = to_categorical(y_train, 10)
y_test = to_categorical(y_test, 10)

# Entrenar el modelo
model.fit(x_train, y_train, batch_size=128, epochs=10, validation_data=(x_test, y_test))

```
Este fragmento de código realiza lo siguiente:

1. **Cargar los datos MNIST**: El conjunto de datos **MNIST** contiene 60,000 imágenes de entrenamiento y 10,000 de prueba, cada una con 28x28 píxeles.
2. **Normalización**: Los valores de los píxeles se normalizan para que estén en el rango [0, 1].
3. **Redimensionado**: Las imágenes se redimensionan para que tengan la forma `(28, 28, 1)` (alto, ancho, canales).
4. **One-hot encoding**: Las etiquetas de las clases se convierten en formato **one-hot**, donde cada etiqueta es representada por un vector binario.
5. **Entrenamiento**: El modelo se entrena con un tamaño de lote de 128 y 10 épocas.

##### **Evaluación del rendimiento**

Una vez que el modelo esté entrenado, podemos evaluarlo en los datos de prueba para obtener su precisión:
```python
# Evaluar el modelo
score = model.evaluate(x_test, y_test)
print(f'Pérdida: {score[0]}, Precisión: {score[1]}')

```
