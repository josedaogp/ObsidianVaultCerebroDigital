La regularización es crucial para evitar el sobreajuste (overfitting) en los modelos, especialmente cuando tenemos conjuntos de datos pequeños. Existen diferentes técnicas de regularización, y aquí veremos dos de las más comunes: **Dropout** y **Data Augmentation**.

##### **Overfitting y Underfitting**

- **Overfitting (Sobreajuste)**: Ocurre cuando el modelo se ajusta demasiado bien a los datos de entrenamiento, pero no generaliza bien en los datos de prueba. Esto puede ocurrir cuando el modelo es demasiado complejo.
- **Underfitting (Subajuste)**: Ocurre cuando el modelo no es capaz de capturar la complejidad de los datos, y su rendimiento es bajo tanto en los datos de entrenamiento como en los de prueba.

##### **Dropout**

**Dropout** es una técnica de regularización en la que se "apagan" aleatoriamente algunas neuronas durante el entrenamiento para evitar que la red dependa demasiado de unas pocas neuronas.

En Keras, puedes añadir **Dropout** a tu modelo de la siguiente manera:
```python
from keras.layers import Dropout

model.add(Dropout(0.5))  # Apaga el 50% de las neuronas

```
Esta capa se agrega entre las capas completamente conectadas para mejorar la generalización del modelo.

##### **Data Augmentation**

El **Data Augmentation** es otra técnica de regularización que consiste en generar variaciones artificiales de los datos de entrenamiento (rotaciones, traslaciones, etc.), de manera que el modelo vea más ejemplos durante el entrenamiento.

En Keras, puedes usar **ImageDataGenerator** para aplicar técnicas de Data Augmentation:
```python
from keras.preprocessing.image import ImageDataGenerator

datagen = ImageDataGenerator(
    rotation_range=20,
    width_shift_range=0.2,
    height_shift_range=0.2,
    shear_range=0.2,
    zoom_range=0.2,
    horizontal_flip=True,
    fill_mode='nearest'
)

datagen.fit(x_train)

```
