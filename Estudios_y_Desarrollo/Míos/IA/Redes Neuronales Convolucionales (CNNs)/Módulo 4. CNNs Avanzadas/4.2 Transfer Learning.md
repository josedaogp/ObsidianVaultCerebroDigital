El **Transfer Learning** es una técnica en la que tomamos un modelo preentrenado (que ha aprendido a realizar tareas complejas como la clasificación de imágenes) y lo ajustamos (fine-tuning) para un nuevo problema.

##### **¿Por qué usar Transfer Learning?**

- **Ahorro de tiempo y recursos**: Entrenar una red profunda desde cero requiere mucha potencia computacional y datos. Usar un modelo preentrenado permite aprovechar el conocimiento de redes previamente entrenadas.
- **Mejor rendimiento**: Los modelos preentrenados están entrenados con grandes cantidades de datos (como **ImageNet**), por lo que tienen una capacidad de generalización bastante buena.

##### **Pasos en Transfer Learning**:

1. **Cargar un modelo preentrenado**: Utilizamos un modelo que ya ha aprendido a reconocer características generales en imágenes.
2. **Congelar las capas iniciales**: Las primeras capas del modelo ya han aprendido representaciones útiles, por lo que no es necesario entrenarlas de nuevo. Las "congelamos".
3. **Añadir nuevas capas de salida**: Añadimos nuevas capas para que el modelo pueda hacer predicciones en nuestro nuevo conjunto de datos.
4. **Entrenar el modelo**: Solo entrenamos las nuevas capas o algunas capas finales de la red.

##### **Ejemplo de Transfer Learning en Keras**
```python
from keras.applications import VGG16
from keras.models import Model
from keras.layers import Dense, GlobalAveragePooling2D
from keras.optimizers import Adam

# Cargar VGG16 preentrenado sin la capa de salida
base_model = VGG16(weights='imagenet', include_top=False)

# Añadir nuevas capas
x = base_model.output
x = GlobalAveragePooling2D()(x)
x = Dense(1024, activation='relu')(x)
x = Dense(10, activation='softmax')(x)

# Crear el modelo
model = Model(inputs=base_model.input, outputs=x)

# Congelar las capas base
for layer in base_model.layers:
    layer.trainable = False

# Compilar el modelo
model.compile(optimizer=Adam(), loss='categorical_crossentropy', metrics=['accuracy'])

# Resumen del modelo
model.summary()

```
En este código:

- Usamos el modelo **VGG16** sin las capas finales (`include_top=False`).
- Añadimos nuevas capas para adaptarlo a una tarea de clasificación de 10 clases.
- **Congelamos las capas base** para que no se actualicen durante el entrenamiento.
