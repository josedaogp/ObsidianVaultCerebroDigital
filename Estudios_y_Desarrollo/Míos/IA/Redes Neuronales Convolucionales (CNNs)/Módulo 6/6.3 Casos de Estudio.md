### 6.3 Casos de Estudio

A continuación, veremos algunos ejemplos de aplicación real de las CNNs en diferentes dominios.

#### 6.3.1 Clasificación de Imágenes

Un caso clásico es la **clasificación de imágenes** de objetos, como en el conjunto de datos **Fashion MNIST**. Este es el caso que acabamos de tratar en el módulo.

#### 6.3.2 Reconocimiento Facial

Las CNNs también se pueden usar para tareas como el **reconocimiento facial**, donde el modelo aprende a identificar características faciales específicas (como los ojos, la nariz y la boca) y las usa para identificar a las personas en una base de datos.

#### 6.3.3 Reconocimiento de Objetos y Escenas

Otro caso de uso importante es el **reconocimiento de objetos** y **escenas** en imágenes complejas. Un modelo de CNN entrenado en este tipo de tareas podría identificar varios objetos dentro de una sola imagen, incluso si están parcialmente cubiertos o en ángulos complejos.
