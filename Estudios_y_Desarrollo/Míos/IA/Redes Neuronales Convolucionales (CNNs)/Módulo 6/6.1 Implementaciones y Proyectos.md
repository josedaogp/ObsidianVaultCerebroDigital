## 6.1 Implementación de un Proyecto Completo de CNN

### 6.1.1 Recopilación y Preprocesamiento de Datos

Imaginemos que estamos construyendo un modelo para reconocer imágenes de ropa (como camisetas, pantalones, zapatos, etc.). El primer paso será recopilar un conjunto de datos de imágenes etiquetadas. Un ejemplo de dataset común para esta tarea es el **Fashion MNIST**, que contiene imágenes de 28x28 píxeles de ropa etiquetadas con 10 categorías.

#### 6.1.1.1 Cargar el Dataset

Podemos cargar el conjunto de datos **Fashion MNIST** usando Keras, que ya tiene este dataset incorporado:

```python
import tensorflow as tf
from tensorflow.keras.datasets import fashion_mnist

# Cargar datos
(train_images, train_labels), (test_images, test_labels) = fashion_mnist.load_data()

# Normalizar imágenes para que los valores estén entre 0 y 1
train_images = train_images / 255.0
test_images = test_images / 255.0

# Reshape de las imágenes para que tengan 1 canal (escala de grises)
train_images = train_images.reshape((train_images.shape[0], 28, 28, 1))
test_images = test_images.reshape((test_images.shape[0], 28, 28, 1))
\```

Este código carga el conjunto de datos y normaliza las imágenes. Al hacer esto, reducimos la variabilidad de los valores de los píxeles y aseguramos que el modelo pueda entrenar de forma más eficiente.

#### 6.1.1.2 Preprocesamiento de Imágenes

Aunque las imágenes ya están normalizadas, es importante asegurarnos de que estén correctamente etiquetadas y que no haya datos corruptos o vacíos. A menudo, las imágenes tienen que ser redimensionadas o giradas para mejorar la robustez del modelo (a esto lo llamamos **Data Augmentation**).

```python
from tensorflow.keras.preprocessing.image import ImageDataGenerator

# Creación de un generador de datos para aumentar las imágenes
datagen = ImageDataGenerator(
    rotation_range=20,        # Rotación aleatoria de hasta 20 grados
    width_shift_range=0.2,    # Desplazamiento horizontal aleatorio
    height_shift_range=0.2,   # Desplazamiento vertical aleatorio
    shear_range=0.2,          # Aplicar cortes aleatorios
    zoom_range=0.2,           # Zoom aleatorio
    horizontal_flip=True,     # Voltear imágenes horizontalmente
    fill_mode='nearest'       # Estrategia para rellenar los espacios vacíos
)

# Ajustar el generador a las imágenes de entrenamiento
datagen.fit(train_images)
\```

### 6.1.2 Construcción de la CNN

Con los datos listos, el siguiente paso es construir nuestra red neuronal convolucional (CNN). A continuación, te guiaré a través de la construcción de una red simple usando **Keras**.

#### 6.1.2.1 Definir la Arquitectura de la CNN

La arquitectura de una CNN básica puede consistir en las siguientes capas:

1. **Capa Convolucional** (Conv2D)
2. **Capa de Pooling** (MaxPooling2D)
3. **Capa Flatten** (para convertir las características extraídas en un vector)
4. **Capa completamente conectada** (Fully Connected, Dense)

Aquí está el código para crear una red simple de CNN:

```python
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Conv2D, MaxPooling2D, Flatten, Dense

# Definir el modelo secuencial
model = Sequential()

# Capa convolucional
model.add(Conv2D(32, (3, 3), activation='relu', input_shape=(28, 28, 1)))

# Capa de Pooling
model.add(MaxPooling2D((2, 2)))

# Aplanar la salida para conectar con una capa densa
model.add(Flatten())

# Capa completamente conectada
model.add(Dense(128, activation='relu'))

# Capa de salida con 10 neuronas (una por cada clase)
model.add(Dense(10, activation='softmax'))
\```

#### 6.1.2.2 Compilación del Modelo

Ahora que hemos definido la arquitectura de la CNN, debemos compilar el modelo. Para ello, elegiremos un optimizador, una función de pérdida y una métrica de evaluación.

```python
model.compile(optimizer='adam',
              loss='sparse_categorical_crossentropy',
              metrics=['accuracy'])
\```

#### 6.1.2.3 Entrenamiento del Modelo

Una vez compilado el modelo, podemos entrenarlo utilizando nuestros datos de entrenamiento.

```python
model.fit(train_images, train_labels, epochs=5, validation_data=(test_images, test_labels))
\```

### 6.1.3 Evaluación del Modelo

Después de entrenar el modelo, es importante evaluar su rendimiento en el conjunto de datos de prueba.

```python
test_loss, test_acc = model.evaluate(test_images, test_labels)
print(f"Accuracy en el conjunto de prueba: {test_acc}")
\```

Este código nos dará la precisión de la red en el conjunto de datos de prueba. Es importante recordar que una precisión alta en los datos de entrenamiento no siempre se traduce en buen rendimiento en datos no vistos, por lo que siempre evaluamos el modelo en un conjunto de datos diferente.

### 6.1.4 Visualización de Resultados

Una forma útil de visualizar cómo está funcionando el modelo es mostrando algunas predicciones y comparándolas con las etiquetas reales.

```python
import matplotlib.pyplot as plt

# Realizar predicciones
predictions = model.predict(test_images)

# Mostrar las primeras 5 imágenes de prueba y sus predicciones
for i in range(5):
    plt.imshow(test_images[i].reshape(28, 28), cmap=plt.cm.binary)
    plt.title(f"Predicción: {predictions[i].argmax()}, Etiqueta: {test_labels[i]}")
    plt.show()
\```
