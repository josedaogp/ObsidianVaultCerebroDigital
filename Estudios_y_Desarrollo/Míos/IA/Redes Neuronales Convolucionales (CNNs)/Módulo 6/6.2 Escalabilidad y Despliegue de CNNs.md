Una vez que hemos construido, entrenado y evaluado nuestro modelo, podemos pensar en llevarlo a producción y hacer que sea escalable para trabajar con grandes volúmenes de datos. En este apartado, veremos cómo hacer que nuestro modelo sea más eficiente y listo para el mundo real.

#### 6.2.1 Modelos Optimizados para Dispositivos Móviles

Una forma de optimizar el modelo es utilizar **TensorFlow Lite**, que está diseñado para dispositivos móviles. Aquí hay un ejemplo de cómo convertir un modelo Keras a TensorFlow Lite:

```python
# Convertir el modelo a TensorFlow Lite
converter = tf.lite.TFLiteConverter.from_keras_model(model)
tflite_model = converter.convert()

# Guardar el modelo TFLite
with open('model.tflite', 'wb') as f:
    f.write(tflite_model)
\```

#### 6.2.2 Despliegue de Modelos en Producción

En la producción, se suele utilizar **TensorFlow Serving** o **ONNX** para servir modelos. Aquí te mostramos un ejemplo simple de cómo guardar el modelo para que pueda ser cargado y servido en producción.

```python
# Guardar el modelo para producción
model.save('fashion_mnist_cnn_model')
\```

Con esto, el modelo ya está listo para ser cargado y utilizado en un entorno de producción.
