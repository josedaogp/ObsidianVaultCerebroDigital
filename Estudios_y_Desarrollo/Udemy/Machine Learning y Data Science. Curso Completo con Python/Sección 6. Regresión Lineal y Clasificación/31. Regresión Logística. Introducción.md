- Se usa para clasificación.
- Es aprendizaje [[20. Algoritmos de aprendizaje supervisado|supervisado]] (necesita un dataset o conjunto de datos etiquetados).
- Basado en [[23. Aprendizaje basado en instancias y basado en modelos|modelos]].
- Modelo lineal generalizado (no es lineal puro).

Al resultado de la función de la regresión lineal se le aplica una función logística. En vez de un valor cualquiera continuo, va a devolver un valor discreto (clasificación).

Lo primero que tendremos que hacer es clasificar nuestro ejemplo dependiendo de características de entrada.
Por ejemplo, si queremos detectar si un correo es spam o no, tendremos que definir características de un correo de spam como por ejemplo, el número de signos de interrogación y exclamación (si tiene muchos posiblemente sea spam).
La clase negativa (correo no es spam) suele representarse con cero.
La clase positiva (correo sí es spam) suele representarse con un uno.

Existen problemas de clasificación binaria (el caso antes expuestos con dos clases, suelen ser sí o no). y clasificación multiclase cuando hay más de dos clases posibles en el conjunto de datos.
## Conjunto de datos de entrenamiento etiquetado
- x = variables de entrada . Puede haber más de una variable de entrada.
- y = variables de salida
- (x,y) = ejemplo de entrenamiento o dataset
- $y \in \{0, 1\} \quad \text{donde } 0 \text{ es clase negativa y } 1 \text{ es clase positiva}$ en nuestro ejemplo de correo spam.
