Mean Square Error (MSE) es la función de coste que se suele utilizar en regresión lineal.
Al principio, los parámetros de la función se inicializarán de forma aleatoria.
La función de error o de coste, se denota con J(theta).

Si utilizamos la MSE como función de coste, se define así:
$$
MSE = \frac{1}{n} \sum_{i=1}^n (y_i - \hat{y}_i)^2

$$
Siendo $\hat{y}_i$ la función hipótesis (lo que habíamos llamado h sub theta de x).

Básicamente se está calculando la diferencia entre el valor proporcionado por la valor hipótesis (el calculado por el modelo) y el valor real del ejemplo de entrenamiento. Así calcula el error que tiene para ese parámetro en concreto.
Se eleva al cuadrado esa diferencia para que siempre sea positivo.
El sumatorio hace que calculemos el error total de todo el conjunto de datos. Luego se divide entre el número total de ejemplos del dataset.
