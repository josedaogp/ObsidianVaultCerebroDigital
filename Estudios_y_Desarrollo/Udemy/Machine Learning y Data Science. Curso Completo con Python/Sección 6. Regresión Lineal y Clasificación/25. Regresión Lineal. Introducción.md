La Regresión Lineal es un sistema de machine learning con las siguientes características:
- Aprendizaje Supervisado (necesitará un conjunto de datos etiquetados para su entrenamiento)
- Aprendizaje basado en modelos (tendrá una función hipótesis)
- Se corresponde con un modelo lineal
- Realiza predicciones computando una suma ponderada de las características de entrada y sumándole una constante conocida como *bias*.
- Intenta predecir valores continuos (regresión)

Suele funcionar bien cuando la representación de los datos tiene una tendencia lineal.

El conjunto de datos de entrenamiento (experiencia pasada) se compone de features (características, variables de entrada) y target value (variables de salida). El conjunto de (x,y) = ejemplo de entrenamiento.
Si cada fila del conjunto (x,y) se define como isubx con tamaño m, m sería el número de ejemplos de nuestro conjunto de datos. xsubn , n sería el número de características o variables de entrada.

Cada conjunto de datos lo representaremos como un DataFrame de la librería pandas con el nombre "df".
