En este video, aprenderás a comprender el funcionamiento interno de un bot diseñado para gestionar citas, incluyendo cómo interactúa con la API para verificar la disponibilidad en el calendario del cliente. Se te guiará a través de la configuración necesaria, la importación de plantillas y la consulta de eventos en Google Calendar, asegurando que puedas replicar los pasos de manera efectiva para minimizar errores. Además, se explicará cómo la inteligencia artificial del bot puede interpretar la información de las citas existentes para determinar la disponibilidad para nuevas reuniones.

Lista de herramientas mencionadas:

- API de Google Calendar
- [**Github**](https://github.com/leifermendez/bot-google-n8n-calendar)
- **[Railway Plantilla](https://railway.app/template/ApzZZF?referralCode=jyd_0y)**

- Configuración de la API
