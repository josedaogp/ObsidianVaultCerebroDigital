## Descripción del Vídeo

  
En este vídeo, se guía al usuario en la creación de un chatbot sencillo que funciona a través de Telegram y utiliza la API de OpenAI para procesar mensajes. Los pasos incluyen:

1. Configuración de credenciales de Telegram mediante BotFather.
2. Generación de un webhook público para recibir mensajes en tiempo real.
3. Configuración del nodo de OpenAI en n8n para enviar y recibir mensajes.
4. Creación de un flujo de trabajo en n8n que permite al chatbot responder automáticamente a los mensajes de los usuarios.
5. Pruebas y ajustes finales para asegurar que el flujo funcione correctamente.

Por ultimo añadir que el bot no tiene de contexto el historial y solamente responde al último mensaje.
