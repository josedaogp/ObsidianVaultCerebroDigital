## Descripción:

En este video, se explica detalladamente cómo implementar acciones en los modelos GPT personalizados. Se muestra paso a paso cómo crear y configurar una acción que permita al GPT recuperar información de servidores externos, utilizando APIs. Se hace una analogía entre el funcionamiento de una API y un camarero en un restaurante, destacando cómo las APIs actúan como intermediarios que permiten a los clientes (usuarios) solicitar información o servicios a los servidores. Se detalla el uso del esquema OpenAPI, explicando sus componentes y cómo estos ayudan a definir y estructurar las solicitudes y respuestas de la API. Finalmente, se presenta un ejemplo práctico de una API de clima. Aun así, la API no funciona bien y por tanto no se puede ver el funcionamiento en directo.

## Lista de herramientas mencionadas:

1. APIs (Application Programming Interfaces)
2. OpenAPI Schema
3. HTTP Protocol
4. JSON Format
5. YAML Format

## Topics del video:

1. Definición y utilidad de las acciones en GPT personalizados.
2. Analogía del funcionamiento de una API con un camarero en un restaurante.
3. Descripción del esquema OpenAPI y sus componentes.
4. Ejemplo práctico de implementación de una API de clima.
5. Configuración de parámetros y endpoints en una API.
6. Uso de autenticación en las solicitudes a APIs.
7. Diferencias entre formatos JSON y YAML en esquemas OpenAPI.
