### Descripción:

En este video, aprenderás cómo crear un modelo GPT personalizado que proporciona datos fundamentales sobre empresas utilizando una API gratuita llamada Alpha Vantage. El instructor te guiará paso a paso en el proceso de obtener una clave API, acceder a la documentación, y configurar un esquema para solicitar información detallada de empresas. Además, se demuestra cómo integrar estos datos en un entorno de ChatGPT para generar respuestas inteligentes y personalizadas, optimizando el análisis de inversión en acciones mediante la combinación de datos precisos y análisis profundo.

### Lista de herramientas mencionadas:

1. [API gratuita Alpha Vantage](https://www.alphavantage.co/)
    1. [Consigue tu clave de API](https://www.alphavantage.co/support/#api-key)
    2. [Documentación](https://www.alphavantage.co/documentation/)
2. ChatGPT

### Topics del video:

1. Obtención de una clave API gratuita.
2. Acceso y comprensión de la documentación de Alpha Vantage.
3. Creación de un esquema de API para la obtención de datos empresariales.
4. Integración de datos en ChatGPT.
5. Generación de respuestas inteligentes basadas en datos fundamentales.
6. Ejemplos prácticos de análisis de empresas como Google y Tesla.
7. Comparación de rendimiento de acciones mediante datos históricos.
8. Mejora y actualización continua del modelo GPT para análisis financiero.
