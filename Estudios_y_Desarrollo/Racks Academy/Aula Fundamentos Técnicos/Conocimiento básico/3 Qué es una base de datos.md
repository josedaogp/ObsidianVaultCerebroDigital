En este video se explica de manera sencilla y coloquial qué es una base de datos y los diferentes tipos de datos que se pueden almacenar en ella. Se abordan conceptos básicos como números enteros, cadenas de texto (strings), arrays y objetos, utilizando ejemplos cotidianos para facilitar la comprensión.

  

#### Topics del video:

- Definición de base de datos
- Tipos de datos (números enteros, strings, arrays, objetos)
- Ejemplos prácticos de cada tipo de dato
- Importancia de la estructura de datos en una base de datos
- Concepto de base de datos relacional y no relacional (mencionado brevemente)
