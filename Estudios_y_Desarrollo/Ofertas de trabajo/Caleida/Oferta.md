**3. Tecnologías en el Tech Stack de Caleida**

> 🚀 **Frontend**
> 
> - **React**: Biblioteca de JavaScript para construir interfaces.
>     
> - **Chakra UI**: Framework de componentes accesibles para React.
>     
> - **Redux (Rematch)**: Gestión de estado global; Rematch es una capa simplificada sobre Redux.
>     
> - **Axios**: Cliente HTTP para hacer peticiones REST.
>     
> - **Clerk**: Solución de autenticación y gestión de usuarios.
>     
> - **Firebase**: Plataforma de backend como servicio (base de datos en tiempo real, hosting, auth, etc.).
>     
> - **Chart.js**: Biblioteca para crear gráficos interactivos en el navegador.
>     
> - **TypeScript**: Superset de JavaScript con tipado estático.
>     
> - **Vite**: Bundler ultrarrápido para desarrollo frontend.
>     
> - **ESLint**: Herramienta de linting para mantener el código limpio y consistente.
>     
> - **Vitest**: Framework de testing ligero, inspirado en Jest, integrado con Vite.
>     

> 🛠️ **Backend**
> 
> - **Django 4.0.10**: Framework web de alto nivel para Python.
>     
> - **FastAPI**: Micro-framework Python para APIs rápidas con ASGI.
>     
> - **Celery**: Sistema de colas para tareas asíncronas en Python.
>     
> - **Huey**: Alternativa ligera a Celery para colas y tareas programadas.
>     
> - **Redis**: Almacén de datos en memoria, usado como broker y cache.
>     
> - **Django Guardian 2.4.0**: Control de permisos por objeto en Django.
>     
> - **Simple JWT 5.2.2 & Python PyJWT 2.6.0**: Librerías para manejo de JSON Web Tokens.
>     
> - **SQLParse**: Biblioteca para parsear y formatear sentencias SQL.
>     
> - **Docker 6.0**: Contenerización de aplicaciones para entornos reproducibles.
>
