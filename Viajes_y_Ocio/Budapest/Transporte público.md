# Mapa metro
![[Mapa metro budapest.png]]
## Horarios metro y precios
Horario: de 4.00 am a 23.15 h. 

Frecuencia: cada 2-3 minutos.

Precios de los billetes: son muy baratos y hay varias opciones según nuestras necesidades:

|                                               |                  |
| --------------------------------------------- | ---------------- |
| **Billete sencillo**                          | 350 Ft (0,90€)   |
| **Bono 10 viajes**                            | 3000 Ft (7,90€)  |
| **Billete reducido metro** (máximo 3 paradas) | 300 Ft (0,80€)   |
| **Billete de transbordo**                     | 530 Ft (1,40€)   |
| **Abono 1 día**                               | 1650 Ft (4,40€)  |
| **Abono 3 días**                              | 4150 Ft (11€)    |
| **Abono  7 días**                             | 4950 Ft (13,10€) |
